# Real Estate Ownership Proof System
Overview
A full-stack real estate ownership proof system enabling users to submit contracts and admins to approve/reject them, with specialized logic for agricultural land (zamam) that tracks area-based ownership percentages, plus a wills feature for users to add inheritance documents. Built with React, Node.js, Express, MongoDB and JWT authentication, it also supports listing approved properties for sale, managing purchase transactions and storing wills linked to user properties.
